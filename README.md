# diegoreiseleicoes.com.br

Site de Diego Reis com a apuração do 2º turno de 2026, usando os dados oficiais do TSE.

Arquivos:
- **index.html**: apuração ao vivo
- **analise.html**: comparação entre o 1º e o 2º turno
- **graficos.html**: gráficos
- **pesquisas.html** e **pesquisas.json**: aba Pesquisas
- **governador.html**: aba Governador

Para atualizar as pesquisas, basta editar o **pesquisas.json**. Em cada pesquisa nova ou alterada, atualize também o campo **"atualizado"** com a data e hora da atualização (formato `AAAA-MM-DDTHH:MM`, horário de Brasília): é ele que aparece no cartão do instituto como "Atualizado em …". O Netlify publica sozinho a cada alteração no repositório.
